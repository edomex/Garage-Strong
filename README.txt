GARAGE STRONG — iPhone Workout Tracker

FILES
- index.html: all app interface and workout logging
- manifest.webmanifest: app settings
- icon.svg: home screen icon
- sw.js: offline cache after visiting from hosted HTTPS

HOW TO USE LONG-TERM ON AN IPHONE
1. Upload all four files together to a static HTTPS website host (for example, GitHub Pages or Netlify Drop). Keep filenames unchanged.
2. Open your hosted address in Safari. Log a test set, save it, refresh, and confirm the History contains it.
3. In Safari, tap Share -> Add to Home Screen -> Add.
4. Use the same Home Screen icon to keep your workouts in one place.
5. Go to Plan & Data -> Export backup JSON regularly, and keep the backup in iCloud Drive or another secure location.

IMPORTANT
Workout entries are stored locally within the browser/web app on your device (localStorage). They are NOT synced across devices or backed up in iCloud automatically. App data can be erased by clearing site data or switching to a different web address/browser. Export backups regularly, particularly before changing phones.

Using the HTML file opened directly from Files is fine for previewing, but local file storage may not persist reliably. Hosting via HTTPS is recommended.
