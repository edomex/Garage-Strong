8-week program

Upper body three times per week, legs once. Sessions usually 45–65 minutes. Keep technique controlled and use appropriate rack safeties.

Equipment & weight calculations

Save your bar weight once. For barbell exercises, type only the plates added in the workout; the app displays and saves the combined total. For dumbbells, enter the complete load of ONE dumbbell (including any removable handle). Machine weights remain stack settings.

If you're unsure of the bar's weight, leave this blank. A blank field means no automatic addition. Existing workouts won't be changed retroactively.

Data backup

Workout data stays in this browser on this device. Export a backup regularly; switching phones, browsers, private mode or clearing website data may erase it.

Import replaces all existing data after confirmation. Export first if needed.

How to use this on iPhone

Host these app files on an HTTPS site, open that address in Safari, then select Share → Add to Home Screen. That gives you an app icon and consistent website storage. Open it online once before using offline.

An HTML file opened from Files may not save data reliably. Use web hosting for long-term tracking.
