How to use this on iPhone

Host these app files on an HTTPS site, open that address in Safari, then select Share → Add to Home Screen. That gives you an app icon and consistent website storage. Open it online once before using offline.

An HTML file opened from Files may not save data reliably. Use web hosting for long-term tracking.
